# Instalar dependências necessárias

Execute os comandos abaixo no diretório do projeto para instalar as bibliotecas usadas:

```bash
# Instalar Firebase e AsyncStorage
yarn add @react-native-firebase/app @react-native-firebase/messaging @react-native-async-storage/async-storage

# iOS
cd ios && pod install
```

Se estiver usando `npm` substitua `yarn add` por `npm install`.
